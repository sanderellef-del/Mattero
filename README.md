# Mattero

Kildekoden til [mattero.no](https://mattero.no) – en åpen samling undervisningsressurser i matematikk for videregående skole (1P, 2P, 1T, R1 og R2).

Laget av Sander, lektor i matematikk.

## Struktur

- `index.html` – forsiden
- `style.css` – felles utseende
- `1p/`, `2p/`, `1t/`, `r1/`, `r2/` – kurssider
- `om/` – om-siden
- `CNAME` – kobler siden til domenet mattero.no (ikke slett)
